## Accounting System
A web-based accounting system developed using Django and Python.

## Functions
Primarily for my personal use

- Journalized Transactions `| Collections | Deposits | Cash Disbursements | Check Disbursements | Liquidation | General`
- Fund Accounting
- Special Accounts
- Ledgers `| General | Subsidiary | Tax`
- Trial Balance
- Bank Reconciliation (Manual flagging of entries, no bank statement importing for now)

The following functions are still not working:
- Individual Receipts (May not be continued)
- Budget
- All financial reports

## Requirements
- [MySQL Server](https://dev.mysql.com/downloads/windows/installer/8.0.html)
- [Python 3.13.5](https://www.python.org/ftp/python/3.13.5/python-3.13.5-amd64.exe)
- Required Python packages in `requirements.txt` (Find requirements.txt inside the released files)
